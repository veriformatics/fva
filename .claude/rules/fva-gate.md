# FVA gate

- Full gate = `scripts/gate` (CI + every closing commit); fast gate = `scripts/gate --fast` (iteration; skips the network/history scanners `osv-scanner`, `gitleaks git`). rc 0 = every step passed; each step prints its wall-clock, failures print their last 20 log lines.
- Steps: `lake --wfail build` (type-check; warnings fail), `lake --wfail test` (`fvatest` + compile-time `#guard`s in `FVATest`), `scripts/test-decoder` (decoder vs the official binary tests + `wasm-tools print` differential + lift kernel check), `scripts/test-numerics` (integer spec + verified float impl vs the official numeric scripts), `scripts/test-floatdiff` (verified float impl vs `wasmtime wast`: case matrix + fixed-seed boundary-biased operands; fast 105,832 assertions, full 1,971,832; generation ≈ 18 s of the full run), `lake --wfail lint` (Batteries `runLinter`), `scripts/check-format` (Lean text format: ≤ 100 columns, no tabs, no trailing whitespace, final newline — Lean has no official formatter), `scripts/test-checks` (planted inputs for the purpose-built checks), shellcheck + `shfmt -d` (scripts/), `.agent/spec-lint`, `scripts/check-pins`, actionlint + `zizmor --offline` (workflows), `gitleaks dir` (+ `gitleaks git` full), `osv-scanner` (lockfiles; full).
- `FVATest` imports the executable modules it runs (spec, impl, tools), never the proof modules: a planted impl bug then still builds the tests, which must catch it on their own (mutation check U12 relies on this).
- `lake build` success alone proves nothing about proofs (accepts `sorry`, custom axioms, kernel bypass); verification claims go through `fva trust` (U7 onward).
- Pins move together: `lean-toolchain` = installed `lean` = Mathlib tag in `lakefile.toml` = `lake-manifest.json` inputRev (`scripts/check-pins`); Renovate groups Lean + Mathlib and never automerges. Scanner binaries = `scripts/fetch-tools` (version + sha256; a Renovate bump fails there until the sha256 is refreshed from the release).

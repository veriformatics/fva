- Every gate step was seen failing on a planted input (U1): build (unused variable under `--wfail`), test (`#guard false`), lint (`unusedArguments` on a theorem), shellcheck (SC2086), shfmt (indent diff), spec-lint (malformed Tasks row), gitleaks (planted AWS key → 1 leak), osv-scanner (`requests==2.19.0` → 20 known vulnerabilities), actionlint (unexpected step key), zizmor (template-injection, rc 14), check-format + check-pins (via test-checks; check-format also passes a 101-column line in a file whose line 3 is the `fva lift` header and fails it when the header sits elsewhere). - Pinned counts ratchet (user ruling on the template's `Engineering` verification-integrity clause: a case changes only in its own unit, on evidence): the official-suite tables (`test-decoder`, `test-numerics`, `test-spec` pass/fail/skip) and the generated-case counts (`test-floatdiff`, `test-difftest` assertions). A move toward the contract (more official assertions pass, fewer fail or skip, more generated cases) lands in the change that causes it, its table diff in that commit body; a move away = a gate change in its own unit, on evidence the pin errs against the contract, after a `.agent/deferred.md` row (its reason + the check that restores it).

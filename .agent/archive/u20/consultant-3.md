### Q4

**Risk order: SegD > SegB; ExtL1B is no longer engine work.**

- **ExtL1B:** `Cut/ExtB.lean:229–249` supplies `extL1B : ExtL1B` and `segA : SegA` via the old stepping machinery. Its domain remains arbitrary `acc < 2^31`, `lim ≤ mem.size`, with reachable overflow and the exact bound-exit witness `p+k=lim` (`Cut/SegA.lean:128–154`). SegC's 2 MiB fuel bounds rule its overflow out (`C/FVATest/Subjects/Lz4C/SpikeC/SegC.lean:143–181`; D `SegCLoop.lean:16–18,39–41`), so it was never a drop-in ExtL1B transfer. Keep the completed common proof; do not charge it as a C/D+ comparison or generalize SegC's restricted invariant.
- **SegB:** arbitrary literal length, near-end memmove/return versus error, wildcopy, then original offset bytes (`Seg.lean:52–97`). C has the constituent call/wildcopy machinery (`C/FVATest/Subjects/Lz4C/SpikeC/Wild.lean:23–99`) and source-byte preservation (`ShortFacts.lean:44–55`; used in `S5.lean:63–73`). Risk = buffer/footprint widening plus exact local/return-state joins; SegC tests none of its stores/calls. S5 is the closest shape, and D+ has the smaller S5 source. No measured SegB cost ranking follows.
- **SegD:** `prologue`/`matchRest`/`SegD` (`Seg.lean:183–244`) include offset 0–7 tables (negative entries represented as `i32`), ordered-overlap copies, widened read footprint for module tables, capacity error **after** prologue writes, far and near wildcopies, and I3's byte tail. The error's changed store and exact final head must survive adapters; proving only successful matches would miss R1's whole-domain requirement. C's normal-form weakness is concrete here: the four-byte S1 block needed eight explicit range facts (`C/FVATest/Subjects/Lz4C/SpikeC/S1.lean:62–80`), and S2 had wrapped-bias recursion failures (`spike-c/report.md:189`). Keep pointers symbolic and memory summaries abstract across joins.

I3 is an untested **decoder loop shape**, not unsupported byte-store semantics: C already proves a memory-evolving byte loop against ordered `fwdCopy` (`S1.lean:10–43`). The residual challenge is its different labels, termination/bounds and composition with wildcopy, not inventing byte semantics. This evidence supports trying C, not assuming SegD ready. Whole-domain exact-root acceptance plus actual union replay, rather than sampled inputs, closes these risks. No SegB/SegD production evidence after the cut-off was used.

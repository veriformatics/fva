# U37 contract — claim domain witnesses (tier: kernel verdict, glue collector)

Purpose: a claim whose input domain is empty holds of every conclusion (TauCetiReview `rubrics/correctness.md`): `∀ x : Nat, x < 0 → x = 1` passes every pre-U37 gate (kernel replay, axioms, layout, links) while it says nothing. Decisions "Claim witnesses" (user ruling) → `fva trust` FAILs a claim whose input domain lacks a kernel-checked inhabitant; the inhabitant = a proof-side theorem whose statement FVA derives from the claim, so the review surface does not grow. Invariant = **domain inhabitation per conclusion path**: for each path, one tuple of inputs satisfying every premise on that path exists (not nonvacuity of the whole statement, not a runnable example, not intent). Consumers: every spec module, `AGENT.md` items 2 + 5, U28g + U31 (land with their witnesses). Review: consultant-20 (1 sound / 9 change / 2 reject; every change adopted below; `.scratch/lwr/u37/consultant-20.md`) + advisor (spike before freezing C2, measured below).

## Interface
- `FVA/Spec/ClaimAttr.lean` (reviewed once): `@[fva_witness C]` = `FVA.witnessAttr : ParametricAttribute Name`; elaboration rejects a target without `@[fva_claim]` and a non-theorem declaration (Lean's parametric attribute: same-module application only).
- `FVA/Spec/Trust.lean` (reviewed once): `inductive Domain | notRequired | required (statement : String) | unavailable (why : String)`; `Claim.domain : Domain`, `Claim.witnesses : List Proof` (accepted, with their axioms), `Claim.rejected : List String` (one line per rejected candidate); `Pass.unwitnessed : ∀ c ∈ r.claims, c.domain = .notRequired ∨ ((∃ s, c.domain = .required s) ∧ c.witnesses ≠ [])`; `Pass.axiom_` ranges over `c.proofs ++ c.witnesses` (a witness resting on `sorryAx` is an `[axiom]` like a proof).
- `FVA/Trust/Verdict.lean` (verified): `ruleUnwitnessed` = one issue per failing claim (`<claim>: input domain without a witness (prove it in a theorem marked @[fva_witness <claim>] typed fva_obligation% <claim>)` + the statement, or `<claim>: domain unavailable: <why>`) + its rejected lines; `ruleAxiom` reads witnesses; `FVA/Proof/Trust.lean` `ruleUnwitnessed_nil` + `verdict_pass_iff` re-proven.
- `FVA/Trust/Obligation.lean` (glue, shared): `inductive Obligation | notRequired | required (e : Expr) | unavailable (why : String)`; `obligation (inU : Name → Bool) (c : Name) : MetaM Obligation` = C1 (`inU n` = n's module is project or subject).
- `FVA/Proof/Lib/Witness.lean` (proof tooling, base): term `fva_obligation% C` = `obligation`'s `Expr` under the name-based classifier (C2) — the authoring route: `@[fva_witness C] theorem C_domain : fva_obligation% C := …`.
- `FVA/Trust/Collect.lean` (glue): `obligation` under the file-based classifier (U7 F2: project + subject = U); candidates = the attribute's imported entries naming C; C2 acceptance; accepted witnesses join the override audit closure (beside proofs) and the export roots (`FVA/Tool/Trust.lean`); text report: per claim `domain:` (printed with binder types, in Lean's raw form: the collector loads no notation extension, U7 F1) + accepted witness names; `--json` additive: `report.claims[].domain {kind, statement|why}`, `witnesses`, `rejected`; `FVA_TRUST_EXPORT=<file>` = a copy of the replayed export (test hook).
- `FVA/Tool/Explain.lean`: `[unwitnessed]` routed by the typed claim fields, never by name mention (an obligation may name other claims).

## Predicates
- C1 obligation `W(C)` (C = an `@[fva_claim]` definition; an in-spec theorem = `[layout]`, no extraction; universe parameters → `unavailable`). U = definitions (`defnInfo`) whose module is project or subject. `head(e)` = repeat until none applies: drop metadata; ζ (a `let` at the head or as the head function); β (a λ head); δ of a U constant at the head (levels instantiated) — at most 256 δ steps per claim, the 257th → `unavailable`. `paths(xs, e)`, `e := head(e)`:
  - `∀ x : A, B` (A β-reduced at its head): A a Prop (kernel: `Kernel.check` + `Kernel.whnf` type = `Sort 0`) with `head(B[x]) = False` → the path ends: `close xs` (A = the refuted statement, never witnessed: `A → B → False` refutes B and witnesses A; `A → ¬B` = premise A + the atom `¬B` (core `Not` stays folded) → witnesses A; the claim constant's own unfolding counts as one δ step); else `paths(xs ++ [x], B[x])`.
  - `A ∧ B` (the conclusion's `And`, never a premise's) → `paths(xs, A) ++ paths(xs, B)` (each path keeps the shared binders: two branches may need different inputs).
  - anything else (`Eq`, `Iff`, `Or`, `Exists`, `Not`, FVA base vocabulary, a stuck matcher/recursor/projection) → `close xs`.
  - `close xs` (innermost first; empty → no path): a premise not mentioned later → `A ∧ acc` (`A` alone at the end); a data binder or a premise a later binder mentions → `∃ x : A, acc` (`True` at the end; level from the kernel). **Every binder counts** (consultant-20 Q3: module origin ≠ inhabitation; `Fin 0` is a core type with no member).
  - `W(C)` = the paths' closures conjoined left to right (no subsumption); no path → `notRequired`; a kernel or elaboration error → `unavailable`. The obligation's shape (`A ∧ w` vs `∃ h`, a trailing `True`) is no public contract: witnesses state it through `fva_obligation%`.
- C2 acceptance: candidate = a theorem in another module than the spec module whose `@[fva_witness C]` names C; accepted iff its level parameters are none and its type is `Expr.eqv` to the collector's `W(C)` ⇒ every replay kernel checks the witness against the obligation itself (no single-kernel conversion; consultant-20 Q6). Else a rejected line: `<w>: states another proposition` (+ both statements printed) | `<w>: universe parameters`; when the project's `FVA.Trust.Obligation` or `FVA.Proof.Lib.Witness` is not FVA base (edited or another version), each rejected line says so. Classifiers: collector = by file (U7 F2); `fva_obligation%` = by module name (Lean core + Mathlib's packages + `FVA.*` outside the claim's package folded, the rest unfolded); a module the two place apart = a rejected witness (fail closed). Planted's `sumToSeven`, 2 Box cheats, Lz4Wasm, 7 synthetic: `match` + `let` premises, sibling branches, refutation, a λ under a project wrapper, `Fin`) → 22/22 `Expr.eqv` between the elaborated witness types and the collector's `W` under `loadExts := false`.
- C3 verdict: `[unwitnessed]` exactly for claims with `required` and no accepted witness or with `unavailable`; text + JSON as Interface.

## Residual (registered, not closed)
- R1 C1's grammar is syntactic: premises inside FVA base vocabulary (reviewed once; `Returns`, `ReturnsAfterWrite` assert fresh instances, `NeverStuck`'s antecedents stay inside its definition), implications inside conclusions (a guarded postcondition `0 ≤ r → …`) and atoms (`Iff`, `Or`, `Exists`) carry no obligation; `fva explain` + `AGENT.md`'s attack list cover them.
- R2 a witness proves existence (`Classical.choice` allowed): no concrete printed input, no case coverage, no evidence the conclusion is nontrivial or the requirement captured.
- R3 the two classifiers can disagree (an edited vendored FVA file, a project module named under a folded root) → a rejected witness with both statements printed, never a silent pass.
- R4 the collector maps project `.olean`s in-process (D62 open): attribute entries + `W` read the same environment as every other fact.

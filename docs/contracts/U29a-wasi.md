# U29a contract — WASI preview1 reviewed model + environment `E` (tier: kernel)

Purpose: the reviewed-once world for WASI processes (Decisions: WASI, D28 claim, C++ example, System layer): a world state, the 20 declared preview1 calls as one semantics over it, the environment `E` that claims assume, and the binding of a module's imports + exported memory to that world. Consumers: U29b (executable host on machine stores = this semantics at `E`'s choice; `fva run`; difftest), U28g (C++ system claim), U29d–f (bustools segments + claim). v3 = v1 + consultant-13's two review rounds (ruling tables at the end).

## Three layers (never conflated)
- W = `world m mem`: the WITX envelope under two named host assumptions (a structure result stores its fields alone, padding unchanged, as wasmtime's wiggle does; a failed call has no effect — wasmtime's chunked stream writes can fail after partial output, outside W). Precise semantics on the profile domain with every WITX-allowed choice, plus labeled over-approximations (any errno with no effect; a call that blocks forever; an arbitrary typed outcome outside the profile) and named pinnings where WITX is silent and W fixes wasmtime 50.0.0's policy for every host (reviewer-5 R5, R11, G2): a directory descriptor keeps no fdflags (p1:1472); `path_open` with a sync fdflag (dsync, rsync, sync) → `notsup`; `fd_fdstat_set_flags` with one → `inval` (p1:1541–1546). POSIX semantics bind W where WITX defers to them: no entry is created in a removed directory (`rmdir`: "no new entries may be created in the directory"). Claims never assume W is small; W bounds what `E` may pick (T3).
- E = a named deterministic virtual host on the profile domain: wasmtime 50.0.0's policy wherever that lies in W (transfers, fd numbering, single-failure errnos, an empty stdin request), named completions elsewhere (enforced rights with declared masks, virtual stat metadata, frozen stated clocks, a 2^63 − 1 file-size limit (as wasmtime on Linux tmpfs), an `mfile` fd fallback, u64 serial numbers running out at 2^64 → `nospc`). Outside the profile `E` constrains nothing, divergence included, so no total-correctness claim passes an out-of-profile call. A claim under `E` covers hosts that behave as `E` on the calls the run reaches; it is not a theorem about wasmtime.
- Run comparison (U29b): `fva run` vs `wasmtime run` = evidence on a tested domain; E's departures from wasmtime (below) are listed in the README + claim docs; a program that observes a departure (prints a stat field, a rights mask, a clock) differs.

## Theorems (`FVA/Proof/Wasi/*.lean`; kernel-checked)
- T1 `stay` (the `World` field).
- T2 typing: every outcome of a bound in-profile call is `HostOutcome.Allowed s c.sig.results` (`[i32 _]`; memory writes keep pages + max).
- T3 (four obligations): (a) `E`'s values are W's explicit choices (`FVA/Proof/Wasi/Policy.lean`): `ofE σ r b` = the choice holding `E`'s value in every field `run` reads for `r` (`none` where `E`'s call fails before the field matters: an empty stdin request, a write at the size limit, no descriptor number below 2^31); `run_ofE`/`step_ofE`: `run`/`step` at `ofE` = at `E`'s choice; `ofE_ok`: on a `Wf` state with u32 iovec lengths (`decode_iovs_u32`: every decoded request) `ChoiceOK σ r (ofE σ r b)` — transfer count ≤ `maxCount` and positive when `maxCount > 0`, descriptor unused + below 2^31, serial number unused, clock reading u64 + monotone, rights = the requested ones, `filestat` fields u64; (b) `Env.Total (world m mem) (E m mem)` on every branch; (c) `(world.restrict E).host ⊆ world.host` (definitional); (d) W's injected failure (`err = some e`) returns errno `e` with world + store unchanged (`exec_err`).
- T4 determinism under `E` (equation form, U29b's `HostOK` seam): for a bound in-profile call `c ≠ random_get`, `(world m mem).restrict (E m mem)` host `σ τ id s vs o ↔ (τ, o) = execE σ c s mem vs` (`execE` = `exec` at `{bytes := []}`); random_get in profile ↔ `∃ b, b.length = len ∧ (τ, o) = exec … {bytes := b}`; proc_exit k ⇒ `o = trapped s ∧ τ.exited = some k`.
- T5 examples (`decide`/`rfl` on concrete states, `simp` where a size has no literal; each expected value derived from a cited source — WITX line, wasmtime p1 line or a probe in `FVATest/Wasi/probes/` — never from running `exec`): the matrix = every call × success + each errno branch `run` has (one example each; branch audit by script at the review) + each field offset/width; plus: init's rights → a libc-shaped `CREAT|TRUNC` open on `State.init` succeeds; seek-only rights permit `(0, cur)`; signed seek boundaries; a two-buffer write transfers the first buffer (count = its length) and a later empty buffer is skipped; a write-prefix with an unused out-of-bounds tail = out of profile; output cells overlapping a buffer = out of profile; a misaligned out-pointer = out of profile; absent vs non-preopen prestat; creation + trunc + trailing `.`/`/`; two opens of one file with independent offsets; unlink + recreate while the old fd still reads the old data; zero-byte I/O at and past EOF; every random byte string of a 2-byte buffer; distinct + stable `ino`s; fd reuse = the greatest freed fd; `spawn` pipes stdout to stdin; `fileAt` reads a created file.

## E's departures from wasmtime 50.0.0 (README + Decisions; difftest-visible when a program observes them)
- Rights: enforced (`notcapable`) + reported as requested; preopen masks = wasmtime's + {fd_datasync, fd_sync, path_filestat_set_size} (base) / + {path_filestat_set_size} (inheriting) — wasmtime ignores rights, derives the open mode from `fd_read`/`fd_write` (a write without `fd_write` → its `badf`) and reports synthesized masks.
- Stat: `ino` = node index + 1, `nlink` 1, times 0, directory size 0 (wasmtime: metadata hash + host values; `dev` 1 in both).
- Clocks: frozen at the stated readings; stdio: non-tty (filetype unknown).
- File size: `E` = wasmtime 50.0.0 on a Linux tmpfs (positioned transfer reaching 2^63 → `inval` everywhere; append from 2^63 − 1 bytes → `fbig`, crossing → cut); on another file system wasmtime refuses appends + sparse writes earlier (ext4: 16 TiB → `fbig`). fd numbering: `E` answers `mfile` at 2^31 (WITX: fd < 2^31); wasmtime counts on to 2^32 − 1, then searches downward (p1:438,445). Serial numbers: `E` answers `nospc` once one past the greatest serial reaches 2^64, lower unused serials notwithstanding (wasmtime: the host file system's inode limit).
- Transfers: `E`'s counts are a virtual policy (first non-empty buffer, stdin ≤ 65,536); wasmtime's stream transfers may be shorter under scheduling or resource limits.
- Global assumptions of `E`: in-profile calls return; no spontaneous, resource or I/O failure; stdin finite and preloaded; stdout/stderr captured whole.
- Errno precedence where several failures coincide in a path call = the stated order (wasmtime: its filesystem layer + the OS).
- Out-of-profile calls: `E` constrains nothing (the run host stops); wasmtime traps at the dereference, traps on a buffer ending at 2^32 (the pointer past it overflows) or ignores an unused pointer.
- Paths: opaque bytes in `E`; wasmtime answers a non-UTF-8 path `ilseq` (both answer a NUL `inval`) — LEAD D4.
- proc_exit k ≥ 126: the model keeps k (the wasmtime CLI reports an error status); random bytes: every byte string.

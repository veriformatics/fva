# U3 contract — Wasm numerics: integers + IEEE-754 floats (tier: kernel)

Purpose: the value-level meaning of every numeric instruction in profile P, reviewed once and shared by every subject (Decisions: Trusted base, Floats). Reviewed spec = `FVA/Spec/Numerics/{Int,Float}.lean`; verified impl = `FVA/Impl/Numerics/{Int,Float}.lean` (kernel-evaluable, proven against the spec); evidence = the official numeric tests + difftest. Consumers: U4 semantics (instruction → op), U8 proof library (rounding-error lemmas), U14 bench (edgeR `calc_cpm_raw`: f64 mul/div).

## Spec (reviewed once)
- N1 Integers (Wasm 2.0 §4.3.2): i32/i64 values = `BitVec 32/64`. Each op is written spec-shaped: `signed`/`unsigned` interpretations into ℤ/ℕ, then back modulo 2^N (e.g. `idiv_s i j` = truncate(signed i / signed j), `none` when j = 0 or the quotient is 2^(N−1)). Partial ops return `Option` (`none` = trap). Ops: add sub mul div_{u,s} rem_{u,s} and or xor shl shr_{u,s} rotl rotr clz ctz popcnt eqz eq ne lt/gt/le/ge_{u,s} extend{8,16,32}_s; conversions wrap, extend_{u,s}. Lean core `BitVec` operations may appear only inside proofs of the impl, not as the spec's definition (the spec mirrors the Wasm text so a reviewer checks it line by line).
- N2 Float formats: `Format` = precision p + emax (binary32 = 24/127, binary64 = 53/1023); bits = `BitVec 32/64`; `classify : bits → {nan s payload (payload ≠ 0), inf s, finite s m e}` per the IEEE 754 encoding (biased exponent, implicit bit, subnormals); finite value = (−1)^s · m · 2^e ∈ ℝ (Mathlib).
- N3 Rounding (IEEE 754-2019 §4.3.1, roundTiesToEven) as a relation on ℝ: `RoundsTo F x r` ⇔ r is a representable value of F nearest to x, a tie broken to the one whose canonical significand is even; `Overflows F x` ⇔ |x| ≥ 2^emax·(2 − 2^−p) (result ±∞ with x's sign). Representable = m·2^e with |m| < 2^p, e within the format's exponent range (subnormals included); canonical significand = the normalized one (subnormal: e = emin − p + 1).
- N4 Operations per Wasm 2.0 §4.3.3, as relations `bits → … → Set bits` (singleton except NaN results): fadd fsub fmul fdiv (exact real result rounded; ±0 sign rules; ∞ and NaN cases), fsqrt (rounded √; −0 ↦ −0; negative ↦ NaN), fmin fmax (−0 < +0; NaN in ↦ NaN out), fabs fneg fcopysign (sign-bit ops, payload preserved), fceil ffloor ftrunc fnearest (integral rounding, ties to even for nearest, sign of zero kept), feq fne flt fgt fle fge (NaN ↦ false except ne; −0 = +0).
- N5 NaN results (§4.3.3 `nans_N{z*}`): canonical NaN set (payload = 2^(p−2), either sign) when every NaN input is canonical (or none), arithmetic NaN set (payload ≥ 2^(p−2), either sign) otherwise. Claims quantify over every allowed result.
- N6 Conversions: `trunc_{s,u}` = `none` (trap) on NaN, ±∞ or out of range, else truncation toward zero; `trunc_sat_{s,u}` saturate (NaN ↦ 0); `convert_{s,u}` = rounded exact integer; `demote` = rounded value (NaN ↦ nans{z}); `promote` = exact value (NaN ↦ nans{z}); `reinterpret` = bits unchanged.

## Implementation (kernel-shaped, U2 lessons: `bif` on `Nat.blt/beq`, direct `Nat`/`Int` ops, no `Decidable`-driven `if` on hot paths, structural recursion)
- I1 Integer ops over `Nat` (values < 2^N) with the spec's `Option` traps; proven equal to N1.
- I2 One rounder `Impl.roundDyadic F s n d e` (`n, d > 0`) for the exact value `±(n/d)·2^e`: ulp exponent `q = max(⌊log₂(n/d)⌋ + e, emin) − M` (`log2Frac`: `Nat.log2` + one comparison), significand `rneDiv num den` (quotient + remainder, ties to even), `encode` (overflow test `2^(E−1) ≤ q + log₂ m`, subnormal, normal, carry). add/sub/mul/div/convert/demote/integral rounding build `(s, n, d, e)` from `sig`/`ex` (a number's magnitude = `sig·2^ex`) and call it. `fsqrt`: exponent made even, significand scaled by `4^(M+2)`, digit-by-digit `isqrt` (structural, fuel = base-4 digits); an inexact root rounds as `r + 1/2` (no rounding boundary strictly between `r` and `r + 1` at that precision). NaN results = `nanOf`: first NaN input with the top payload bit set, else `+nan(canon)`.
- I3 Theorems: `roundDyadic_eq` (= `gridRound`, the ulp-grid rounding) + `ieee_iff_grid` (prover-3: `Ieee F r v ↔ v = gridRound F r` for `M ≥ 1`, `E ≥ 2`) → `roundDyadic_mem`; `nanOf_mem`; per op `impl ∈ spec` (equality for comparisons + non-NaN conversions); every impl op total and kernel-evaluable.

## Rulings on consultant-3 (C1–C5, D1–D7)
- C1 keep ℝ (Mathlib) for the reviewed spec; compute with exact integer/rational data. C3 keep the ℤ-shaped integer transcription (`Int.tdiv`/`Int.tmod`, shift counts mod width); core `BitVec` ops differ at the edges (x/0 = 0, signed overflow wraps, shift by width = 0) and appear only in proofs. C4 keep full NaN nondeterminism as `Set`; a deterministic impl is one proven witness.
- C2: the spec transcribes Wasm's own rounding definition (`ieee_N`: exact numbers, ±limit candidates, candidate pairs, `even_N`, `rectify_N`) — declarative and line-by-line comparable with §4.3.3; the IEEE overflow threshold and the constructive exponent/quotient rounder are theorems. Mathlib `round` ties toward +∞ and is not used; `roundEven` is defined.
- D1 the rounder theorem is bit-level and signed: `roundFrac F s n d` (d > 0) ∈ `ieee F ((−1)^s · n/d)` with the zero/infinity cases visible. D2 conversions check the truncated integer (−0.9 →u 0; −2147483648.9 →s MIN). D3 promote/demote judge canonicality in the source format and pick from the destination's NaN set (the spec's equations write `canon_N` where prose + tests mean the source `canon_M`; transcribed per prose). D4 floats use the spec's own syntax (`(1 + m·2^−M)·2^e`, subnormals at `emin`), with `fbits`/`ofBits` round trips and uniqueness proven (adequacy below). D5 sqrt: integer sqrt with remainder on a nonnegative scaled significand, zero handled separately. D7 comparisons return the spec's i32 `bool` (0/1) at this layer.
- Adequacy (D4, consultant C2): `Ieee F r` is total and functional (exactly one result for every real), `nans F zs` is nonempty, `ofBits (fbits z) = z` for well-formed `z` and `fbits (ofBits b) = b`; each op's result set is nonempty and, outside NaN cases, a singleton.
- C5/E-evidence: E1 records selected/excluded assertions per script (pinned in `scripts/test-numerics`); adds a normative case matrix (every spec bullet of every op hit at least once, incl. negative checks of the NaN-set predicates) and fixed-seed boundary difftest (E3). The claim that the 3.0 numeric scripts equal 2.0's is withdrawn; the scripts are evidence only for operators whose semantics 3.0 did not change.
- D6 E4 budget (frozen before the impl): one f64 mul or div on ordinary operands ≤ 3,000 kernel unfoldings and ≤ 50 ms user via `decide`; worst cases (subnormal results, overflow, maximal exponent gap) ≤ 10,000 unfoldings.

## Rulings during the build
- fmul zero sign: the Wasm equations (2.0 and main) cover `±0·±0` only and send `±0·q` to `ieee_N(0) = +0`; IEEE 754 §6.3 (sign of a product = XOR of the operand signs, zeros included; recalled, standard not re-read) and the official tests (`f32.wast` 824/836: `mul -0x0p+0 0x1p+0 = -0x0p+0`) give the XOR sign → the spec transcribes IEEE (`IsZero z₁ ∨ IsZero z₂ → {±0 by XOR}`), noted at the definition; upstream report draft → U17. Other ops route no exact zero through `ieee_N` where IEEE signs it (checked: add/sub/div/sqrt/integral rounding/conversions/promote/demote have explicit zero cases).
- E1 result: every official float script passes in full (f32/f64 2500 each, cmp 2400 each, bitwise 360 each, conversions 593, float_misc 470, float_literals 99); float_exprs 651 pass + 168 skipped (not straight-line → U5).
- E2 firing (`.claude/rules/fva-checks.md`): round toward zero, ties away, `min(−0, +0) = +0`, `rem_s(MIN, −1)` trap, demote saturating to max-finite → each fails ≥ 1 official assertion.

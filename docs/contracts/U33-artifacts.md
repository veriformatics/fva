# U33 contract — artifacts out of the repo (tier: data)

Ruling (user, Decisions "Repository contents"): third-party artifacts + benchmark archives leave the repo, fetchable from `veriformatics/fva-artifacts` releases; FVA-built examples linking third-party code are rebuilt by script; FVA's own third-party-free fixtures stay. Trigger: the pinned edgeR 4.99.10 files vanished upstream (R-universe → 4.99.12) between 2026-11-07 and 11-11 → `fetch-corpus` 404 on every fresh host; CI also raced its parallel corpus fetches.

Tier = data: every consumer re-validates at use (sha256 pin per fetched file, `fva trust`'s byte-identical re-lift + link check, the gate's pinned counts + surfaces) ⇒ one structural validator (sha256 pins + `check-notices`) + live spot-checks (anonymous download + cmp).

## Moves
- M1 releases on `fva-artifacts`, files unchanged, notes = sha256 + license + upstream + version + corresponding source: `edger-4.99.10` (binary package + source tarball + GPL-2.0 text); `subject-builds-v1` (lz4-c.wasm, lz4-c-O1.wasm, lz4-flex.wasm, glm-iround.wasm, runorm-pflog.wasm, CppEH's eh.wasm + notices + license texts); `bench-runs-v2` (`bench-runs.tar.xz`, `xz -9 -T1` over a sorted, owner-0, fixed-mtime tar = reproducible = `bench/runs` at the removal commit's parent, NOTICE's edgeR source line → the `edger-4.99.10` release).
- M2 manifest = `bench/subjects/manifest.json`: `edger-*` urls → fva-artifacts; each published `builds[]` entry + the runs archive gain a `url`; `scripts/fetch-bench <id>` fetches subjects + builds + archives by id (sha256-checked, cached under `.cache/bench/downloads/<id>/`).
- M3 untracked + gitignored, populated by script at use: `bench/runs/` (`bench/fetch-runs`: archive sha256 + a stamp), every manifest `places` path (`scripts/fetch-subjects`: fetch-bench by id, then an atomic copy) = `FVATest/Subjects/{Lz4Wasm,Lz4C,Lz4C/O1,GlmIround,CppEH,EdgerCpm}/*.wasm|edgeR.so` + `bench/subjects/{wasm-pflog,wasm-glm}/*.wasm`, and the subjects' `Lifted.lean` (`scripts/test-subjects`: `fva lift` = the committed bytes before the move); their NOTICE files leave with them.
- M4 keyed remainder (mutation digest inputs, `FVATest/Mutate/config.json` `tests[].files`: `scripts/fetch-corpus`, `scripts/test-difftest`, `bench/subjects/wasm`; on main's table ≈ 1,311 of 3,791 rows depend on them: test:spec 1,004, test:difftest 167, test:numerics 26, test:decoder 19, survivors 93, inconclusive 2) rides in the first landing commit whose update starts after U33 and re-keys every row anyway (U28b; U28a's update was already running on its own tree): `fetch-corpus`'s edgeR url → fva-artifacts, `bench/subjects/wasm/*.wasm` fetched by `test-difftest`; until then `scripts/gate` places the edgeR archive from fva-artifacts into `.cache/corpus` before its one corpus fetch.
- M5 FVA-built examples with third-party code (CppEH at U28f's landing, bustools at U29c) = a committed build script + pinned toolchain; the gate rebuilds + checks the emitted-byte sha256; `.wasm` + `Lifted.lean` never committed.

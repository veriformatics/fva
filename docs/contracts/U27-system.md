# U27 contract — system layer (tier: kernel)

Purpose: process-level claims: a world state σ (files, streams, exit status) beside the Wasm configuration, host calls moving σ, an embedder that grants fitting growth, an environment profile `E` narrowing host outcomes, machine runs bridged to `SysMust` (Decisions: Growth policy, System layer, Machine). Consumers: U28g (C++ function claim: returned values), U29a (WASI world + `E`), U29b (executable WASI host on the machine), U29d–f (D28 segments + claim). Contract review: consultant-7 (4 sound / 5 change, all adopted) + advisor.

## Spec (reviewed once)
- S1 growth policy (`FVA/Spec/Exec/Step.lean`): `inductive StepP (H : HostSem) (fits : Bool)` = Step's rules; `memoryGrowFail` gains `fits = true → ∀ a mem, f.inst.mems[0]? = some a → s.mems[a]? = some mem → mem.grow n.toNat = none`, `tableGrowFail` the same over `f.inst.tables[x]?`, `s.tables[ta]?`, `t.grow n.toNat r = none`; `abbrev Step H := StepP H false` (the premise is vacuous: every rule means what it meant); `Steps`, `Must`, `May`, `PartialCorrect`, `Call*` unchanged over `Step`. `fits = true` = an embedder that grants every growth within the limits; a claim using it states that assumption.
- S2 system (`FVA/Spec/Exec/System.lean`, new):
  - `NoHost : HostSem := fun _ _ _ _ => False`.
  - `structure World` = `St : Type`; `host : St → St → HostSem` (a host call's outcomes + the world change it makes); `exited : St → Option Nat` (`some k` = the process ended by `proc_exit k`); law `stay : host σ τ id s vs .diverged → τ = σ` (a call that never returns moves no world: otherwise divergence + a world change terminates).
  - `SysStep W fits (σ, c) (τ, d) := W.exited σ = none ∧ ((StepP NoHost fits c d ∧ τ = σ) ∨ (StepP (W.host σ τ) fits c d ∧ ¬ Step NoHost c d))`: an exited process takes no step (`proc_exit` absorbing); a transition a host-free rule explains under any growth outcome never moves the world. Supersedes the Decision's formula (the exit gate is new; the exclusion over `Step NoHost` keeps its meaning and makes restriction inclusion definitional).
  - `inductive SysOutcome (St)` = `returned (σ) (s : Store) (vs : List Val)` | `exited (σ) (s : Store) (code : Nat)` | `abnormal (σ) (s : Store)`; `SysFinal W (σ, c)`: `returned σ s vs` ⇔ `W.exited σ = none ∧ Final c (.returned s vs)`; `exited σ s k` ⇔ `W.exited σ = some k ∧ c.store = s`; `abnormal σ s` ⇔ `W.exited σ = none ∧ Final c (.trapped s)` (U28b adds the uncaught exception). Command reading: `returned` from `_start` = exit 0 (wasi-sdk returns without `proc_exit`), `exited k` = exit k, `abnormal` = abnormal; a function claim keeps the values + store.
  - `proc_exit k` encoding (pinned for U29a): the host outcome = `trapped` with the post-call store, the successor world `exited = some k`; `SysFinal` reads the exit marker before trap classification and `SysStep` admits no successor, so the guest continuation never runs and the pre-exit effects stay in σ. A host `trapped` outcome with a live successor world = `abnormal`. `proc_exit` is never `diverged`.
  - `inductive SysMust W fits Q` = `done` (`SysFinal` + `Q`) | `next` (a successor exists + every successor `SysMust`).
  - Environment: `World.restrict W E` (`host := W.host ∧ E`, same `St`, `exited`; `stay` inherited); `Env.Total W E := ∀ σ id s vs, (∃ τ o, W.host σ τ id s vs o) → ∃ τ o, W.host σ τ id s vs o ∧ E σ τ id s vs o` (relative nonemptiness; U29a supplies the WASI profile's witnesses).

## Theorems (`FVA/Proof/Exec/System.lean` + Det/Machine extensions; kernel-checked ⇒ no property tests)
- T1 policy: compat (every existing proof over `Step` via the abbreviation; `Step.c` references → `StepP.c`, the vacuous premise at the grow-fail constructions); `StepP.mono` (H ⊆ H'); `StepP.fits_le` (`StepP H true ⊆ Step H`); `StepP.fits_total` (`(∃ d, Step H c d) → ∃ d, StepP H true c d`), `StepP.toStep`; `host_free_iff`: `StepP H fits c d → (Step NoHost c d ↔ StepP NoHost fits c d)` (the Decision's exclusion = the spec's).
- T2 system: `exited_no_step` (`W.exited σ = some k → ¬ SysStep W fits (σ, c) y`); `sysFinal_unique`, `sysFinal_no_step`, `SysMust.outcome` (a SysMust state's finishing outcome satisfies `Q`); `sysStep_restrict_le`: `SysStep (W.restrict E) true x y → SysStep W false x y`; nonemptiness: `Env.Total W E → (∃ y, SysStep W false x y) → ∃ y, SysStep (W.restrict E) true x y`.
- T3 determinism under `fits`: `instrUnique fits` (growth unique at `true`), `seqUnique`/`atUnique`/`uniqueStep fits`; `seq_complete` + `step_complete` over `StepP H fits` (the existing proofs, generalized); `sysMust_of_step` (`W.exited σ = none`, unique core step, σ kept), `sysMust_trap` (`W.exited σ = none`, pending trap ⇒ `abnormal σ`), `sysMust_returned` (`W.exited σ = none`, values ⇒ `returned`), `sysMust_exited` (`W.exited σ = some k` ⇒ `exited σ c.store k`).
- T4 host focus: the stepper's `atInstr` reports a host invoke as `Out.host a vs` (was `.stuck`; `step` unchanged); `hostFocus c = some (a, id, vs)` (next redex = `invoke a` of `.host ft id` on the arity-sized argument suffix `vs`, through value prefixes, labels + frames, store `c.store`) ⇒ no `Step NoHost` successor; every `StepP H fits` successor = `hostResult c o` with `H id c.store vs o`; each such `o` gives that step. `sysMust_host`: `hostFocus c = some (a, id, vs) → W.exited σ = none → (∃ τ o, W.host σ τ id c.store vs o) → (∀ τ o, W.host σ τ id c.store vs o → SysMust W fits Q (τ, hostResult c o)) → SysMust W fits Q (σ, c)`; `host_diverged_not_must`: an allowed `.diverged` outcome at a live host focus ⇒ `¬ SysMust W fits Q (σ, c)`.
- T5 machine: `MState.uniq fits` (head instruction no choice point); `step_simU`: `m.Inv → m.uniq fits → m.step = some m'` ⇒ U26's stepper path is unique at every source configuration (bulk loops + one-step cases; a pending trap ends a path through `must_trap`); `machineRun_must` (U26 T3): `m.Inv → m.runU false n = (m', false) → Final m'.abs o → Q o → Must H Q m.abs`; `machineSegment_sysMust`: `m.Inv → W.exited σ = none → m.runU true n = (m', b) → SysMust W true Q (σ, m'.abs) → SysMust W true Q (σ, m.abs)` (continuation form: fuel exhaustion + choice-point stops are prefixes, never termination); `MHost W` = executable host on machine stores: `run σ id s vs = some (τ, mo)` ⇒ sound (`W.host σ τ id s.abs vs mo.abs`), invariant-preserving (`s.Inv` ⇒ every store `mo` carries satisfies `MStore.Inv`); `hostStep` + `abs` commute through the whole machine continuation (`hostResult`); `machineRun_sysMust` = segments + host steps where each host call's `(world, outcome)` pair is the only allowed one (`∀ υ o, W.host σ υ id s.abs vs o → υ = τ ∧ o = mo.abs`), ending at an explicit `SysFinal` witness with `Q`. Many-outcome calls (`random_get`) use `sysMust_host` with a universal continuation.
- T6 demonstration (`FVA/Proof/Lib/SysExamples.lean`, built by `lake --wfail build`), each a theorem:
  - growth + many outcomes: memory 1 page, max 2; host `poke` writes any byte at a fixed `L < 65536` + increments a counter world (result never read); `memory.grow 1`; store at 65536 (the new page); return ⇒ `SysMust (W.restrict E) true (returned …)` for all 256 outcomes via machine segments + `sysMust_host` (the symbolic byte by defeq first: `Chunks.set`/`leafSet` never branch on the value, a read of `L`'s 64-byte leaf would; the finding → U29e's framing note; else enumeration).
  - exit: a host marks exit 7 after an observable write; the guest continuation (another write + `unreachable`) never runs ⇒ `exited σ s 7` with the pre-exit effects; `exited_no_step` on an exit-marked world at a `nop`.
  - host trap ⇒ `abnormal` (live successor world); allowed divergence ⇒ `¬ SysMust`.

# U28d contract — the optimized machine over P′ (tier: kernel)

Purpose: run P′ executions on the U26 machine — exception handling (`try_table`, `throw`, `throw_ref`, handler clauses), tail calls (`return_call*`), typed references (`call_ref`, `ref.as_non_null`, `br_on_null`, `br_on_non_null`) — every machine step = reference-stepper steps (Decisions: Machine; D29 P′; U28b runtime rules), so the public runner (U28e), the C++ EH example (U28f/U28g) and the D28 checkpoints (U29) run P′ code on one verified engine. Consumers: U28e (official P′ scripts on the machine), U28f (EH execution of `eh.wasm`), U28g + U29 (`machineRun_must` / `machineSegment_sysMust` / `machineRun_sysMust` through caught throws, host calls under handlers), `scripts/test-spec` + `test-char` (2.0 outcomes unchanged).

Review: consultant-11 (7 sound / 12 change / 0 reject; every change adopted below; `.scratch/lwr/cons/c11/verdicts.md`).

## Interface (verified implementation, `FVA/Impl/Exec/Machine.lean`)

- I1 `Ctl.handler (n : Nat) (cs : List Catch) (saved : List Val) (rest : List AInstr)`; `wrap` rebuilds `vals saved.reverse ++ [.handler n cs inner] ++ rest`; `abs` otherwise unchanged (U26). No frame in the entry (Q3).
- I2 `try_table bt cs body` with `k` params and `n` results (`bt`'s expansion in the current frame), at least `k` operands: one step = Ref's `tryTable` step: `stack := stack.take k`, `code := body.map .plain`, `ctl := .label n [] [] [] :: .handler n cs (stack.drop k) rest :: ctl` (innermost first: the result label inside the handler, as `[.handler n cs [.label n [] (vals args ++ body)]]`); frame + store unchanged; expansion failure or fewer than `k` operands → `none`. Handler exit (code empty, top entry `.handler`) = `handlerExit`: operands kept above `saved`, `rest` restored, the entry popped — no arity check (`StepP.handlerExit` has none).
- I3 Exceptions, one reference reduction per machine step (Q2):
  - `throw x` delegates to `Ref.instrStep` (allocation, `throwing a`).
  - `throw_ref` with `.ref .null` on top: trap with the other operands + `rest` kept (`throwRefNull`), an explicit machine case.
  - `throw_ref` with `.ref (.exn a)` on top and other operands or a nonempty `rest`: operands + `rest` dropped, exactly `[.ref (.exn a)]` + `[throw_ref]` left (`throwRefInstrs`); no entry popped in this step.
  - exact throwing state (`stack = [.ref (.exn a)]`, `code = [throw_ref]`), innermost entry:
    - `.label`: popped, its `saved` + `rest` restored around the re-exposed throw (`throwRefLabel`; the next step drops them);
    - `.frame`: popped, its caller frame + `saved` + `rest` restored (`throwRefFrame`);
    - `.handler` with a clause left: `Ref.catchStep` on the first clause in the current frame (Q3) — taken → the clause's output with the handler entry popped and its `saved` + `rest` restored (`throwRefCatch*`); not taken → the entry kept with the remaining clauses, the throwing body unchanged (`throwRefHandlerNext`); missing tag lookups decline a clause, `catch_all*` is unconditional (`catchStep` as is);
    - `.handler []`: popped, its `saved` + `rest` restored (`throwRefHandlerEmpty`);
    - no entry: no step (`step = none`), `ending = .thrown a`.
  - any other operand shape at `throw_ref`: no step.
- I4 Tail calls: `.returnInvoke a` pops labels + handlers to the innermost frame (`retInvokePop`; the current frame's handlers dropped, outer callers' kept) and replaces it: caller frame, the callee's `k` arguments (k from `s.funcs[a]`'s expansion, wasm or host function) above the frame entry's `saved`, `[.invoke a] ++ rest` = Ref's `returnInvoke` step; underflow or no enclosing frame → `none`. `return_call*`, `call_ref`, `ref.as_non_null`, `br_on_null`, `br_on_non_null` delegate to `Ref.instrStep` (as U26's plain instructions).
- I5 Control: `brPop` + `retPop` discard handler entries between the target and the top without counting them as branch depth (a handler is no branch target); `outerFrame` + `trapOut` pass handlers (a trap is never caught); a frame boundary still stops a branch.
- I6 Endings + choice points: `ending` gains `.thrown a` (`ctl = []`, `stack = [.ref (.exn a)]`, `code = [.plain .throwRef]`). `uniq` stays strict = `Ref.uniqueStep` of the abstraction: a `throw_ref` with other operands or a nonempty `rest` is a choice point (`Ref.atUnique` false). A separate local predicate `admin` marks the administrative throw steps (`throwRefInstrs` and the exact-throwing-state reductions) that `runU`/`sysRun` may take at a choice point (Q1); NaN results, ungranted growth and non-singleton hosts stay real choice points. Both read the machine state locally (top operands, code head, top entry): no `abs`, no recursive `seqThrow` on the ordinary step path.
- I7 Scope: `Inv` stays memory-only (`∀ mm ∈ m.store.mems, mm.Inv`); `MState` stays data-only (no frame snapshot, no closure); a malformed argument or failed lookup may give `none`, every successful step simulates under the same `Inv`. One-way simulation is not machine progress: completeness/adequacy stays deferred (Decisions: Machine).
- Out of the interface: GC, host-originated exceptions (Decisions: hosts never throw).

## Theorems (`FVA/Proof/Exec/Machine.lean`, `MachineSys.lean`; axioms = {propext, Classical.choice, Quot.sound})

- T3 Bridges through throws, public statements unchanged (`machineRun_must`: final-state witness + `Q` mandatory, either fuel Boolean; `machineSegment_sysMust`: either growth policy, live world, any finite prefix, any `SysMust` continuation at its endpoint; `machineRun_sysMust`: `HostOK` + endpoint continuation mandatory, an exit-marked world stops before guest execution), now over runs that take `admin` steps:

  - per-step continuation transfer (Q1): from `Must Q` at the machine's successor of an `admin` step, `Must Q` at the original state — forward transport along the finite administrative normalization (`step_throw`: every successor keeps store + frame, strictly decreases `seqSize`, keeps the nearest-handler boundary or the uncaught exception; `steps_throwHandler`/`steps_throw`; a forward-closure lemma for `Must` at a non-final boundary; `Must.outcome` at a final one), then `must_throwHandler` (caught: `seqThrow … = some (.inr L)`) / `must_throw` (uncaught) backward;
  - system analogue: live world kept; administrative paths valid under both `fits` values (proven here via `stepP_free` + `step_throw`, not assumed); forward `SysMust` transport by `next` + `sysFinal_no_step`; then `sysMust_throwHandler` / `sysMust_throw`;
  - `runU_sim`'s internal "every source along the trace is unique" → a continuation-transfer result (strict-path lemma kept for unique steps); induction over `runU`/`sysRun` keeps the arbitrary-prefix endpoint interface, a fuel boundary mid-unwinding included; no typing precondition added.
- T4 Host calls under handlers: `layerK`/`wrapK`, `seq_layer_host`/`seq_wrap_host`, `wrapK_fill`, `abs_host` gain the handler case (`Ref.HCtx.handler`): a host call or resumption under any mixed handler/label/frame stack commutes with `abs`; a tail call to a host drops the current frame's handlers before the call; `HostOK`, host traps, allowed divergence and exit-first stopping keep their U27 meaning.
- T5 `instantiate_sound` unchanged (U28c shared candidates); a thrown start function = an unsuccessful instantiation.
- Finite-prefix semantics: a thrown ending has no step; a pending throw with an enclosing entry continues while fuel lasts; `b = false` alone is not termination (choice point, missing host, stuck); prefix composition, final/abnormal witnesses, world exit priority and real choice stops keep their U27 meanings; no claim infers all-input or total correctness from the stop Boolean.

## Rulings (consultant-11 Q1–Q3)

- Q1 Admit throws in `runU`/`sysRun` through administrative continuation transfer (T3); strict `stepNU` reasoning kept for unique steps. Grounds: U28g's all-input claim needs caught-throw transfer under binders; per-throw hand composition would export the normalization proof to every claim.
- Q2 One reference reduction per machine step: keeps `Sim.one` + the stronger uniqueness clause (a whole unwind can pass a non-unique intermediate state, which `Sim` forbids); no second normalizer. Revisit only with a measured bottleneck + a `Sim` amendment.
- Q3 Current frame at the handler, no snapshot: popping a `.frame` entry restores the caller, so the frame current when a handler is innermost is the one `catchStep` resolves tags in; a snapshot would restore stale locals.

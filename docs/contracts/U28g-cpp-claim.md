# U28g contract — C++ all-input system claim by data-oblivious framing (tier: kernel)

v3 = v2 + advisor (position maps, not restriction; seams between `put`-representable states only; the fallthrough congruence named as the main proof; a compiled `trun` trace before any kernel measurement; the seam mechanism + re-run count pinned in E0). v2 = v1 + consultant-18 (astra; `.scratch/lwr/u28g/cons18-verdicts.md`: K3 sound, K1 K2 K4 K5 K6 K7 change, 0 reject — every change adopted: support + validity premises, `Inv`-guarded `Eqv`, `local.tee`'s delayed overwrite, store-memory byte identity, the active-stack seams, continuation-form composition, host framing on `wasiHost … none`, measured preflight, layered plants, evidenced fallback).

Purpose: D29's C++ example (Decisions: C++ example, user ruling: all inputs): for every 32-bit input `x`, `eh(x)` called in a fresh WASI process under the reviewed model + `E` returns `x + 1` (even) or `x ⊕ 0xa5a5a5a5` (odd, through `throw` → `catch` in the shipped libc++abi + libunwind code, its one host call answered). Method: data-oblivious framing — a concrete twin input's machine run, evaluated by the kernel, transfers to every input that the run carries without inspecting it (F1, proven once), short symbolic steps where the code computes on or moves `x` across the active stack (F2). Consumers: acceptance `D29.cpp-trust-{default,paranoid}`; later all-input claims over data-oblivious code; U29e reuses F1's memory/position/validity layer + host-framing interface (arithmetic transfer = new rules, designed there).

## Method
### F1 framing (`FVA/Proof/Exec/Oblivious.lean`; proof library outside every spec closure — no `FVA/Impl` change, no mutation rows)
- Positions `Pos` = `byte mi a` (store memory `mi`, address `a`: identity survives calls into other instances) | `top i` (local `i` of the running frame) | `local k i` (local `i` of the caller frame saved in control entry `k`, counted from the bottom) | `saved k j` (operand `j` of entry `k`'s saved vector). Patches `ts : List (Pos × TVal)`, `TVal` = a byte or a `Val`; `put ts m` applies them (bytes by trie write, slots by list update).
- Valid patches `PatchOK ts m`: positions `Nodup`; `byte mi a` → store memory `mi` exists, `a < its size`, byte < 256 (an out-of-range write aliases the trie: `Chunks.set` keeps the low address bits); `top`/`local`/`saved` → the slot exists (a slot-type premise only if a lemma needs it: `Inv` covers memories alone). `put` keeps `Inv` under `PatchOK`.
- `Eqv m m'` = `Inv m ∧ Inv m'` ∧ every component equal except `store.base.mems` (never read: `MStore.abs` overrides it) and memories equal byte-extensionally with equal pages/max/depth. `step_eqv` (needs both `Inv`: a malformed trie loses data on a write), `abs` equal under `Eqv`, `put` respects `Eqv`, the checker's verdict representation-independent under `Eqv`.
- Checker `tstep (ps : List Pos) (m : MState) : Option (Pos → Option Pos)` = the next step's position map (old → its new position, `none` = killed or dropped), or `none` when the step inspects a position; `trun` composes the maps along the run, the patches follow them (`move f ts = ts.filterMap fun (p, v) => (f p).map (·, v)`). Built from the step kind actually taken (consultant-18 K1 table):
  - reads (reject): a load/packed load whose successful range meets a tainted byte of the addressed memory; `memory.copy`'s source range (overlap included); `local.get` of a tainted `top`; any restoration of a tainted saved operand to the active stack (block/label/handler exit, frame pop, `br`/`return`, `retInvoke`/`framePop`, throw unwinding through a label/frame/handler, a catch) — rejected even when a following administrative step would drop it; a host call other than the covered ones.
  - writes (kill exactly the successfully written positions): stores, packed stores, `memory.fill`, `memory.copy`'s destination, `memory.init` (bounds failures and zero lengths write nothing); `local.set` of a tainted `top`; `local.tee` keeps the taint (the stepper emits `[v, v, local.set x]` over the old frame: killed at that later `local.set`).
  - moves: `invoke` → `top i ↦ local k i` with `k` = the old control length; a frame pop → that entry's `local k i ↦ top i`, the popped frame's `top` positions dropped; positions in discarded saved vectors dropped; entries above unchanged by bottom index; `trapOut` keeps the outermost frame's locals + bytes, drops the rest (the claim's path never traps); growth keeps in-range byte positions.
  - everything the checker does not represent (active stack, code, globals, tables, element/data segments, exception + tag fields) = equal on both sides by the theorem's premise.
- `tstepHost`: the host call bound by the module's import index, arguments = the equal active stack; covered = `environ_sizes_get` (two aligned, in-bounds, disjoint 4-byte outputs, no guest-memory input; its overflow/error branches write nothing) — its successful writes kill the byte positions they cover; any other call → `none`.
- Fallthrough congruence (the main proof; first generic proof = a spike on a handful of constructors): the machine hands the whole frame + `store.abs` to `Ref.instrStep`, `Ref.catchStep` and `bt.expand` ⇒ lemmas that these read locals only through `local.get`/`local.set`/`local.tee` and memory bytes never (`catchStep` the instance alone: eh's frame is on top, x in local 0, when its handler fires); a failing spike = stop-rule evidence.
- Theorems: `step_put` (one step: `PatchOK ts m`, `support ts ⊆ ps`, `tstep ps m = some f`, `m.step = some m'` ⇒ `(put ts m).step = some m''` with `Eqv m'' (put (move f ts) m')`, `PatchOK` kept, `uniq`/`admin` equal); `host_put` for `wasiHost m mem none` (the world identical); `sysRun_put` = continuation form over a certified run: `trun ps n (σ, m) = some f` (exactly `n` admitted transitions, each successful — fuel = a cutpoint, never a finality claim) → for every `Q`, `SysMust W true Q (σ', (put (move f ts) m').abs) → SysMust W true Q (σ, (put ts m).abs)` where `(σ', m', _) = sysRun … n (σ, m)` (matches `machineSegment_sysMust`; hides the `Eqv` bookkeeping).
### F2 seams (each starts + ends at a `put`-representable state — x only in patches, never on the active stack or in code values — or at the final state; free `x`, parity hypothesis `hx` where needed; uniqueness/admin justified per step as the backward bridge requires)
- S1 launch → parity: `MState.ofInvoke ms a [.i32 x]` (x on the active stack) → the wrapper frame → `local.get 0` (+ its value step) → `call $eh` → eh's prologue → `local.get 0; i32.const 1; i32.and; i32.eqz; br_if` under `hx` → ends with x in eh `top 0` + the wrapper's `local k 0`.
- S2 odd: `local.get 0` (+ value step) + `i32.store` (after F1 ran `local.tee 2`, untainted) → byte patches `[p, p+4)` added beside the local patches.
- S3 odd: after `__cxa_begin_catch` returns: `i32.load` (reads the byte patches: value = x by the trie write/read lemmas; its value step) → `local.set 0` (eh `top 0 = x` again; byte patches kept).
- S4 odd: after `__cxa_end_catch` returns: `local.get 0`, `i32.xor`, `local.set 0`, `br 2`, the epilogue's `local.get 0; return` → the wrapper → `call $__wasm_call_dtors` and its invoke step → ends with the result = `saved k 0` of the dtors frame entry. S4′ even: `local.get 0; i32.const 1; i32.or; local.set 0` + the same epilogue + the dtors call (`x | 1 = x + 1` for even x).
- S6 the dtors frame exit (restores the saved result) → the wrapper's return → `SysFinal … (.returned τ s [result])`, `τ.exited = none`.
- Seam mechanism: generic step lemmas (∀ m with this code head + stack shape) + kernel-decided facts about the noncomputable twin state at the cut (code head, stack, frame shape), as WasiGc's `run`; each fact re-runs the twin prefix in every replay kernel ⇒ one bundled `decide` per cut point.
### F3 composition
- Odd: S1 → F1 (allocation, `local.tee 2`) → S2 → F1 (`__cxa_throw` … `environ_sizes_get` … `throw` … unwinding … the catch's `local.set 3; local.set 0` … personality … `__cxa_begin_catch`) → S3 → F1 (`__cxa_end_catch`) → S4 → F1 (dtors interior, stopping before the frame exit) → S6. Even: S1 → S4′ → F1 (dtors) → S6. Twins: `x = 1` (odd) and `x = 0` (even).
- Each F1 segment: its `trun` certificate + the twin's run by the kernel, one declaration each (a segment's start state = the concrete run from the launch state re-evaluated, no materialized checkpoint — re-evaluation cost measured, K5); the final patch list output with the endpoint; `launch_sysMust` (or its `machineRun_sysMust` core) closes from the launch configuration.
- Path lemma (evidence, outside `r1`): the odd run's store gains exactly one exception instance, the even run none (`Eqv` carries the exception store); the host-call count stays with `Run`'s 72-input control.

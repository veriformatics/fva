# U29b contract — executable WASI host, `fva run`, first system claims

v3 = v2 (v1 + consultant-14 Q1–Q8: Q1 sound, Q2–Q8 change, all accepted; advisor-reviewed) + two departures found while proving U29b1 (named below: T3(ii) policy, E1 placement). Base = U29a's model as landed (reviewer-5 rulings in: regions below 2^32, W pinnings, `off_t` limits, removed directories, u64 serials).

Purpose: make U29a's model usable: an executable host on machine stores whose every answer is `E`'s only outcome (U27 `HostOK`), so `machineRun_sysMust` turns a machine run into a `SysMust` claim under `E`; `fva run` running WASI commands on the verified machine; evidence that model + host + IO glue match wasmtime on a tested domain; the first system claims. Consumers: U28g (C++ claim: no `random_get`, T1 + T3), U29c–f (bustools: host + binding/preflight APIs), AGENT.md users. Three Tasks rows, in order: U29b1 (critical path) → U29b2 → U29b3.

Claim kinds kept apart in every text: an executable run (evidence), a fixed-input proof (`SysMust` from one `State.init`), a fixed-bytes proof (`Eseed`, a proof helper), an all-random-values `E` claim (U29e alone).

## U29b1 — host + launch canonicalization + first claim (tier: kernel)
- H1 `FVA/Impl/Exec/WasiHost.lean` (mutation scope = the `exec` group: a new group would change the mutation manifest and stale every row; the WASI spec `wasiHost` reaches joins the `helpers` group): `wasiHost (m : Module) (mem : Nat) (rand : Option Bytes) : State → Nat → MStore → List Val → Option (State × MStore × MHostOut)`. Answers iff `bind m id = some c`, `ms.mems[mem]?` exists, `inProfile σ c ms.abs mem vs`, `c ≠ random_get ∨ rand = some b`, every write inside the memory. Answer = `step σ (decode c mm.abs a) {bytes := b}` (U29a's `step` verbatim); `ok ws` → writes via `MMem.writeBytes` in order + `returned [i32 0]`; `err e` → store unchanged, `returned [i32 e]`; `exit k` → store unchanged, `trapped`. Else `none` (fail closed: unbound id, out of profile, unseeded `random_get`, a write outside memory). `rand` = the bytes of THIS call (`run` cuts/pads them). H1b `answerHost X (σ, m) : Option (St × MState)` = the machine after answering its pending host call with `X` (`hostCall` + `X` + `hostResume`, the step `sysRun` takes): the IO driver runs `sysRun` with `wasiHost m mem none`, which stops at a `random_get`, draws fresh bytes `b`, applies `answerHost (wasiHost m mem (some b))`, and resumes — one fixed `X` per `sysRun` call, a new one per random call.
- H2 commute lemmas (`FVA/Proof/Wasi/Host.lean`): `MStore.abs` of the answered store = `exec`'s store; `MStore.Inv` kept (`writeBytes_inv`).
- T1 `wasiHost_ok : HostOK ((world m mem).restrict (E m mem)) (wasiHost m mem none)` (via U29a T4 `restrict_host_iff` + H2; `proc_exit` via `step_exit_iff`).
- T2 seeded soundness: every answer of `wasiHost m mem (some b)` (and so every `answerHost` step of the driver) is allowed in `(world m mem).restrict (E m mem)` (no uniqueness: `E` admits every byte string). A seeded run or `∀ b` over runs reusing one `b` never yields an `E` claim (successive draws differ: two one-byte calls compared); `Eseed` + its `HostOK` = U29e's helper, absent from reviewed claims. U29e proves each reached random call's continuation for every byte string (`restrict_host_random` + `sysMust_host`).
- T3 launch canonicalization, generic (every `ModuleValid` module importing functions alone; T4 instantiates it, U28g + U29c consume it): `hostMStore m := {base := hostStore m, mems := []}`; from `Machine.instantiateU fuel (hostMStore m) m (hostImports m) = some (ms, inst)` (init code run by `runU false`, final state `returned []`), `inst.exportFunc name = some a` and `Launch m name args c mem` ⇒ `c = invokeConfig ms.abs a args ∧ inst.exportMem "memory" = some mem`. Stages: T3(i) its own lemma `init_values_unique` (`FVA/Proof/Valid/InstantiateUnique.lean`): any two `Instantiated` witnesses' initializer values are equal, hence (`alloc_inst_eq` + `allocModule` on equal values) their allocated store + instance — route: globals by declaration order (global k reads imports + the first k definitions, `Valid/Module.lean:108–113`; `const_singleton`, `value_of_step`), then table + element initializers (globals fixed), `allocModule`'s instance independent of initializer values; T3(ii) from that one allocated configuration the `runU false` certificate gives `Must` (`machineRun_must`, `Must.final`) ⇒ one terminal store (departure from v2's `fits = true`: `Instantiated` is stated over `Steps` = `Step` = `StepP · false`, and a `fits = true` certificate covers only `StepP · true` executions); T3(iii) `instantiate_sound`/`initRun` soundness builds the canonical witness (signature, export, argument conditions checked). A plain `run` success is no uniqueness certificate.
- T4 first system claim (U29a's `cmd`, `proc_exit 0`): `(∃ c mem, Launch cmd "_start" [] c mem) ∧ ∀ c mem, Launch cmd "_start" [] c mem → ∀ σ₀, σ₀.exited = none → SysMust ((world cmd mem).restrict (E cmd mem)) true (fun o => ∃ τ s, o = .exited τ s 0) (σ₀, c)` (explicit exit 0; any live world, no `Wf` needed: `proc_exit` reads no state) by T1 + T3 + `machineRun_sysMust`.
- T4′ progress counter-claim: `Ediv σ τ id s vs o := E cmd 0 σ τ id s vs o ∨ (τ = σ ∧ o = .diverged)`; `¬ SysMust ((world cmd 0).restrict Ediv) true Q (σ₀, c₀)` on the canonical live start (advance to the `proc_exit` call, `host_diverged_not_must`): the claim depends on `E`'s progress clause.
- Public API (vendored + base manifest + olean pins): `hostMStore`, `wasiHost`, `answerHost`, `instantiateU`, `launch_canonical`, `launch_of_instantiateU`, `launch_sysMust` (a concrete `sysRun` equation from the launch → `SysMust` under `E` for every launch; an all-input claim such as U28g's needs a symbolic method over `machineRun_sysMust` on top), `sysRun_runU`, `sysMust_forward_uniq`; no consumer imports scratch or test-only modules.
- Evidence: E1 T1–T4′ kernel-checked (`lake build --wfail`), standard axioms; independent-kernel replay (every bundled kernel, default + `--paranoid`) of T4 and its closure — T2 (`wasiHost_sound`, `answerHost_sysStep`), T3(iii) `launch_of_instantiateU` and T4′ (`cmd_needs_progress`) stay Lean-kernel only, no claim consuming them in U29b1: T4 = the `@[fva_claim]` of an in-tree subject `FVATest/Subjects/WasiExit/` (the minimal command as a committed WAT-built `.wasm`, `Lifted.lean` = `fva lift`'s output regenerated + `cmp`'d, claim over `Lifted.module`, a `Neg/*` claiming exit 7), replayed by `scripts/test-subjects` in default + `--paranoid` — its proof closure pulls T1, T3, `HostOK`, `machineRun_sysMust` + the U26/U27 machine theorems; both runs' walls recorded (departure from v2's self-package claim: `fva trust` fails a claim whose statement names no subject (`Pass.vacuous`, `FVA/Spec/Trust.lean`), and T4 names only spec constants + the program, so it is a subject claim); E2 plants with actual killers recorded: host ignores `inProfile`; host writes one byte off; `err` stores a result; `proc_exit` returns; unbound id answered; U29a P13 (`E` admits divergence) re-run → the first failing declaration recorded (T4′ = the direct semantic check); E3 mutation `--update` (H1 = new `FVA/Impl` scope); proof boundary (proved) reported apart from IO (tested).

## U29b2 — `fva run` + run evidence (tier: kernel for the stateful execution code; IO = trusted glue graded by tests)
- Launch inputs: `State.args` = basename(wasm path) :: ARGS (UTF-8; FVA's `--` consumed by its parser); `State.env` = the `--env K=V` strings in option order, duplicates + empty values kept, split at the first `=`, a missing `=` rejected; preopens in `--dir` order, default guest name = the lexical `HOST` token (overlap checked on canonical host paths, guest spelling kept); clocks `[0,0,0,0]` (frozen virtual readings: a named departure); the command requires `_start : [] → []`, no start function, no `_initialize`, an exported `memory`, and rejects unresolved imports at load, used or not (wasmtime does) — `--help` + README list these.
- Randomness: default = exactly the requested number of fresh host-RNG bytes at each reached `random_get`, then the shared verified host with that call's bytes; an RNG error = rc 2 (infrastructure), never a guest result. `--random HEX` = deterministic fixed-bytes mode (every call reuses HEX, cut/zero-padded), labeled as such (no wasmtime equivalent; not a seed).
- Driver + endings: an IO driver advances the pure machine + host at host-call boundaries (or bounded `sysRun` segments), emits each new stdout/stderr suffix once, flushed before continuing; segment fuel exhaustion resumes the next segment; any whole-run limit explicit + documented. Exit classes: `proc_exit k < 126` → rc k; `k ≥ 126` → rc 1 + a diagnostic keeping k; `_start` returns → rc 0; a trap (incl. a pending trap inside control frames) → rc 134; an uncaught exception → rc 1; FVA diagnostics = its own stable text (no wasmtime backtraces), guest stderr byte-exact. Distinct rc-2 errors, cause named: unanswered host call (out of profile, unbound import, write outside memory), nonunique numeric choice (NaN), stuck state, exhausted resources — never a success; this partial-run boundary = a named departure.
- Filesystem boundary: finite regular files + directories only, disjoint canonical roots; symlinks, special files, regular-file hard links rejected before the run (U29a models no shared node identity); final trees exported from `State.roots` (not only open fds); sync after return, `proc_exit`, trap, uncaught exception or an unsupported-call stop (earlier file effects kept on a nonzero status); a tree diff applied in place (roots + untouched entries stay); capture/emission/sync failure → rc 2 + the path + a partial-effect warning; exclusive access assumed; host visibility only at sync-back, no atomic commit — named departures; stdin finite + preloaded.
- Evidence: E4 manifest committed before grading (oracle version + flags; compiler/sysroot recipe + binary hashes; wasi-testsuite SHA, paths, language, selected IDs; every exclusion with a reason independent of FVA's result — profile, link/command shape, filesystem shape, scalar/pointer domain, input assumptions; each case's oracle basis: wasmtime exact bytes | named `E` departure | relational check for random/clock observers); the harness fails on missing, duplicate or unclassified rows; an unexpected failure never becomes an exclusion in this unit. Exact-equality runs on two fresh copies of one initial tree (same guest names, basename argv[0], args/env bytes, stdin): raw stdout, guest stderr, rc, every relative path + kind, every file's bytes (empty files + dirs included); failures keep command, input hashes, captures, diffs. E5 blind tester corpus (glue): argv/env edge cases (empty, space, Unicode, option-like, consumed `--`, duplicates, first-`=`); `HOST` vs `HOST::GUEST`, multiple roots, closed preopen still synced, nested + empty dirs, NUL/0xff contents, create/truncate/remove/type change, untouched siblings, unlinked-open files; endings after file + stream effects, every Q5 class, unused unresolved import, fuel/nonunique stops; emission once per write, stdout/stderr order, first chunk visible before termination; read/write/sync failures, rejected inputs, malformed options; fixed-seed properties for the option parser + tree import/export/sync round trips. E6 glue plants (actual failing test recorded each): drop an empty argument; deduplicate env keys; canonicalize a guest name; emit a suffix twice; drop final tree changes on rc ≠ 0; omit a deletion/truncation; turn a sync error into rc 0; known-false harness inputs in `test-checks` (altered byte, missing case/file, wrong rc). E7 merge the four `D28.run-{process-empty,process-values,files,exit7}` acceptance IDs when green; CLI help characterization; README WASI section (profile, `E`, the departures matrix, `fva run` usage).

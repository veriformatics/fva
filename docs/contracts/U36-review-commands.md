# U36 contract — review-module commands + nested user namespaces (tier: kernel verdict, glue collector + sandbox)

Purpose: `[syntax]` saw only constants typed `ParserDescr`/`TrailingParserDescr`/`Macro`/`TermElab`/`CommandElab`/`Tactic` in a review module. Commands that run code while the module elaborates, stop it or reconfigure it leave no such constant, and D65's rebuild + kernel replay accept what they produce (a valid definition). Seen red on the pre-U36 trust code (`fva trust . --spec-module FVATest.Cheats.<C>.Spec --root-module FVATest.Cheats.<C>`, rc 0 each): `MetaCmd` (the claim exists only as `run_cmd … elabCommand` output: the review surface shows a metaprogram) → PASS; `MetaExit` (`#exit` after the first claim, a second claim below it: claims = 1, a reader sees 2) → PASS; `MetaInit` (`register_option` = an `initialize`: code every later import runs, no listed word) → PASS. Sandboxed project code could create user namespaces (kernel attack surface it never needs): a build target's `unshare --user true` → rc 0. Sources: TauCetiTools `tauceti_tools/assets/scripts/check_source_options.py` ("reject option overrides and metaprogramming"), TauCeti `.github/workflows/pr-build.yml` (bwrap `--disable-userns`).

## Interface
- `FVA/Spec/Trust.lean` (reviewed once, imports nothing): `commandTokens`, `attributeTokens`, `attributeSuffixes`, `registersCode`; `ReviewModule.commands : List String`; `Pass.syntax_ := (∀ m ∈ r.reviewModules, m.syntaxExts = [] ∧ m.commands = []) ∧ r.subjectSyntax = []` (one conjunct per tag: the tag stays `[syntax]`).
- `FVA/Trust/Verdict.lean` (verified): `ruleSyntax` = one issue per module with declarations (`declares syntax, elaborators or initializers: …`) + one per command entry (`<module>: <token> at line <n> (runs code or changes elaboration)`); `FVA/Proof/Trust.lean` `ruleSyntax_nil` re-proven, `verdict_pass_iff` unchanged in form.
- `FVA/Trust/Lines.lean` (glue): `step` (one tokenizer step; `codeSpans` = its loop, D11 counts unchanged), `termSpans`, `interpolated`, `listedIn`, `listedTokens env src : Array (String × Nat)`.
- `FVA/Trust/Collect.lean` (glue): `isInit` (`regularInitAttr`/`builtinInitAttr` parameter present: works under `loadExts := false`, as `implementedByAttr`); `syntaxExts` + `subjectSyntax` = `isSyntaxExt ∨ isInit`; `commands` = `listedTokens` over the module's source (`<token> at line <n>`).
- `FVA/Tool/Sandbox.lean` (glue): `Mode = full | nested | noNet | off`, `Mode.word`/`Mode.ofWord` (the `--sandbox-mode` hand-off to `trust-run`, so build, `lake env`, D65 rebuild, exporter share one choice); `full` = `--unshare-all --unshare-user --disable-userns` (`--disable-userns` requires `--unshare-user`; `--unshare-all` only tries it); `nested` = `--unshare-all` (today's full); `noNet` unchanged; `fva explain` takes `choose`'s mode as before.

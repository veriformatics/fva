# U28a contract — profile P′: syntax, binary grammar, decoder, profile boundary (tier: kernel)

Purpose: decode every P′ module (Decisions: D29 profile P′) with the U2 guarantees (sound + complete + functional against a reviewed grammar), freeze the representation every later P′ layer builds on, and make the profile boundary one versioned, independently checked fact. Consumers: U28b (runtime + `Step`), U28c (validation + soundness), U28d (machine), U28e (runner), U28f/U29c (C++ + bustools lifts), U31 (GC, if D51 picks WasmGC). Normative pins: Wasm 3.0 SpecTec `859d3232` (`specification/wasm-3.0/1.2–1.4`, `2.1–2.4`, `4.0–4.4`, `5.1–5.4`, `7.1`), testsuite `44f1503f`. Contract review: consultant-8 (round 1: 4 sound / 5 change / 1 reject; amendment round: 6 sound / 4 change — every change adopted below) + advisor. Spec diff review (R1–R11 fixed before reading, vs 3.0 @ `859d3232`): reviewer-1 — 10 pass, R9-F1 (`Module.inP2` let tag imports + exports through; S3 excludes both) fixed + re-reviewed pass.

## Profile P′ (= the productions of `FVA.Spec.Binary`)
- In: Wasm 2.0 P (U2) on 3.0's grammar + exception handling (`tag` section + imports/exports, `throw`, `throw_ref`, `try_table` with its four handler clauses, `exnref`) + tail calls (`return_call`, `return_call_indirect`, `return_call_ref`) + function references (`call_ref`, `ref.as_non_null`, `br_on_null`, `br_on_non_null`, `ref.null ht`, nullable/non-null references to `func`/`extern`/`exn`/a type index, table initializer expressions) + `rec` groups of final function types without declared supertypes (both spellings: the bare function type and `0x4F` with an empty supertype list — one 3.0 AST, `SUB FINAL ε (FUNC ft)`).
- Fidelity: each FVA production is a 3.0 production restricted to P′ constructs — the same bytes decode to the same AST (3.0's element kind `0x00` = non-null `(ref func)` included). So a decoded module is well-formed Wasm 3.0, and a binary `assert_malformed` whose bytes decode is false (runner: FAIL, no longer `skip: rejected only by validation`).
- Out, decoder verdict `unsupported`, class named in the message (`FVA.Profile.Excluded`; the first excluded construct in byte order, U2's best-effort policy; T1–T3 cover `ok` alone):
  - `gc-types`: composite `0x5E`/`0x5F`; sub types `0x50` (non-final) or with a supertype; heap types `any eq i31 struct array none`;
  - `bottom-types`: `nofunc noextern noexn` (3.0's bottoms of the func/extern/exn hierarchies; a scope choice — no pinned P′ script uses them — not a GC construct);
  - `gc-instructions`: `0xFB`, `ref.eq` `0xD3`;
  - `simd`: `0x7B`, `0xFD`;
  - `threads`: `0xFE`, shared limits `0x02`/`0x03`/`0x06`/`0x07`;
  - `memory64`: limits `0x04`/`0x05`;
  - `multi-memory`: an instruction's memory index ≠ 0 (memarg flags `2^6 ≤ n < 2^7` with index ≠ 0; `memory.size/grow/fill/copy/init`). Memory counts, data-segment and export memory indices decode (as in U2) and stay validation's (U6 `oneMemory`, index ranges);
  - `legacy-exceptions`: `0x06 0x07 0x09 0x18 0x19`.
  Every other grammar violation = `malformed`.

## Cross-layer API (frozen for U28b–e; a change = a contract amendment)
- A1 Syntax (this unit, `FVA/Spec/Syntax.lean`, first-order type records with derived `DecidableEq`; `Instr`/`Expr` stay nested): `AbsHeapType` = `func | extern | exn`; `HeapType` = `abs a | idx x`; `structure RefType { null : Bool, heap : HeapType }` (`RefType.funcref`/`externref`/`exnref` = nullable abstract, `@[match_pattern]`); `ValType` = `num | ref`; `FuncType` unchanged; `RecType := List FuncType` (empty groups kept: zero type indices); `Module.types : List RecType` + `Module.typeList := types.flatten` (the type index space); `structure Tag { type : Nat }` + `Module.tags`; `structure Table { type : TableType, init : Expr }` + `Module.tables` (short form ⇒ `init = [.refNull tt.elem.heap]`, 3.0's `TABLE tt (REF.NULL ht)`); `ImportDesc.tag x` (type index), `ExportDesc.tag x` (tag index); `Catch` = `tag x l | tagRef x l | all l | allRef l`; new `Instr` = `throw x | throwRef | tryTable bt cs body | returnCall x | returnCallIndirect x y | callRef x | returnCallRef x | refAsNonNull | brOnNull l | brOnNonNull l`; `refNull (ht : HeapType)`; `MemArg` unchanged (memory index implicit 0, offset now `u64`).
- A2 Closed types (U28b–c), SpecTec's single family: `HeapType` gains `def (d : DefType) | rec (i : Nat)`, `DefType = { group : RecType, idx : Nat }` (closed group + projection), mutual-nested with `RefType`/`ValType`/`FuncType`; `DecidableEq` hand-written in `FVA/Impl` (no derive for nested mutual types; the instance's type is its proof). Obligations frozen now: roll each group at its flattened offset `x` (indices `[x, x+n)` ↦ `rec 0…n−1`, earlier indices ↦ the already-closed `def`s, a forward reference outside the group = invalid; SpecTec `1.2` roll/unroll, `2.4` sequential group validation); substitution never enters a closed `def`'s group (SpecTec removes rec substitutions under a rectype); well-formedness = every group's contents well-formed under its own rec binder (rec indices below the group's size, nested `def`s well-formed in their own scope) + projection in bounds + no free source index in a closed or runtime type, established by closure and preserved by unrolling (negative API test: a singleton group naming `rec 1`); every syntax annotation is closed at its entry point (locals, block/select/`ref.null`/`call_ref` types, global/table/segment/import/tag types), so subtyping and equality only meet closed types; type identity = equality of closed terms (canonical group + projection; `tag.wast`: another projection or a singleton for a group member mismatches); P′ subtyping on closed well-formed types = nullability ≤ + heap equal or `def _ ≤ func`; a null value is typed at every closed well-formed nullable type (3.0 `REF NULL BOT` + subsumption, `Reftype_ok` premise kept); the validator's unreachable operand bottom (`OpType.bot`) stays; U28b's representation spike measures closed-type `DecidableEq` in the kernel (a chain of earlier-type references, unequal-but-similar groups).
- A3 Runtime (U28b): null = `Ref.null` without payload (3.0 `REF.NULL_ADDR`); `Ref.exn a`; `Store.tags : List TagInst` (`type : DefType`), `Store.exns : List ExnInst` (`tag` = tag address, `fields : List Val`); `ModuleInst.types : List DefType`, `.tags`; `FuncInst.type : DefType`; `ExternVal.tag a`; frame locals `List (Option Val)` (unset non-defaultable = `none`, distinct from a written null; validation's init state resets at block exits, runtime values persist); `Outcome.thrown s a`; handler = an administrative layer `handler n catches` outside the result label, catch clauses tried in order by tag address (imported aliases share an address); tail calls replace the frame and drop its handlers. Store extension frozen: `Store.Extends` keeps every existing tag (identity) and exception (tag + fields) and allows append-only allocation (3.0 `Extend_taginst`/`Extend_exninst`/`Extend_store`, `7.1`); exception validity = fields typed by the tag's closed parameter types (`7.1` exception rules). Owners: monotonic value typing + `StoreOK` + host-extension lemmas = U28b–c.
- A4 Validation (U28c): context locals carry init flags (3.0 `init t`; instruction types list the locals they set; block exit restores the entry flags); `C.types : List DefType`, `C.tags`; `Valtype_ok` (indices in range) where A2 closes; table initializers typed under `C'` + constant; tag types = function types with empty results; `ref.func : (ref dt)` + stack subtyping + segment typing migrate together (S3's projection removed).
- A5 GC path (U31, if D51 picks WasmGC): new `AbsHeapType` constructors, `RecType := List SubType` (`{ final, supers, comp }`), declared-supertype subtyping, `0xFB` instructions; A1–A4 stay (identity never by unfolded `FuncType` equality, subtyping a relation, the decoder's `0xFB` slot exists).
- A6 Obligation map: syntax, grammar, decoder, lift, re-encoder, classifier, manifest = U28a; `Step` + stepper + `uniqueStep` + `must_throw` + store extension = U28b; typing + validator ⇔ spec + progress/preservation = U28c; machine + `Sim` = U28d; runner (`assert_exception`, tag import matching by closed `DefType`, in-profile = oracle + syntactic classifier + static profile (at most one memory; named exclusions), pinned P′ scripts + their per-command execution goldens) = U28e. Until U28c validation keeps the 2.0 profile (S3), so no P′-only construct reaches execution.

## Spec (reviewed once)
- S1 `Syntax`: A1.
- S2 Binary grammar (`FVA/Spec/Binary/*`), 3.0 productions restricted to P′: `HeapTypeB` (`0x70 func`, `0x6F extern`, `0x69 exn`; `idx x` = non-negative `s33`, any LEB spelling); `RefTypeB` (`0x63 ht` nullable, `0x64 ht` non-null, abstract byte alone = nullable); `ValTypeB` = num | ref; `SubTypeB` = `functype` | `0x4F` + an empty `vec(typeidx)` + `functype`; `RecTypeB` = `0x4E vec(subtype)` | one subtype; `TagTypeB` = `0x00 x`; `TableB` = `tabletype` | `0x40 0x00 tabletype expr`; `LimitsB` = `0x00 n` | `0x01 n m`, `u64`; `MemArgB` = flags `n:u32` (`n < 2^6` ⇒ alignment n; `2^6 ≤ n < 2^7` ⇒ alignment `n − 2^6` + memory index `u32` = 0) + offset `u64`; memory instructions' memory index `u32` = 0, any LEB spelling; `CatchB` = `0x00 x l` (catch) | `0x01 x l` (catch_ref) | `0x02 l` (catch_all) | `0x03 l` (catch_all_ref); opcodes `0x08 x` throw, `0x0A` throw_ref, `0x1F bt vec(catch) instr* 0x0B` try_table, `0x12 x` return_call, `0x13 y x` return_call_indirect, `0x14 x` call_ref, `0x15 x` return_call_ref, `0xD0 ht` ref.null, `0xD4` ref.as_non_null, `0xD5 l` br_on_null, `0xD6 l` br_on_non_null; element kind `0x00` = `(ref func)`, flag 0 = `(ref func)`, flag 4 = `(ref null func)`; import/export kind `0x04`; tag section id 13 between memory (5) and global (6).
- S3 Validation keeps the 2.0 profile until U28c (`FVA/Spec/Valid/*`): `ModuleValid` gains `profile : m.InP2` — singleton rec groups; no tags, tag imports or tag exports; every value type at an entry point (function types, locals, globals, table types, block and `select` annotations, `ref.null` heap types, nested bodies included) = num or nullable `func`/`extern`; element segment types `func`/`extern` of either nullability, a non-null one initialized by `ref.func` alone (3.0 types every initializer at the declared type; no other 2.0 constant expression is non-null); table initializers = the short form's — and 2.0's typing of element segments reads the nullable projection `t.nullable` (context, `table.init`, instance + store typing, instantiation alike) (3.0 decodes func-index segments as non-null `(ref func)`; 2.0 types `ref.func` as `funcref`); the memarg offset bound `< 2^32` (3.0 `Memarg_ok`; `u64` offsets now decode); P′-only instructions have no typing rule (invalid). ## Implementation (verified, `FVA/Impl/Decode/*`)
- I1 decoder = U2's `Res` reader extended; every new production one parser; `unsupported` only at the out-of-profile points above, each with its `Excluded` class.
- I2 kernel cost (`.scratch/lwr/u28a/kernel-cost.md`; model = inferred from scaling probes, `.claude/rules/fva-kernel-cost.md`): per-call cost tracks the callee's body, byte reads on one numeral retain each shifted remainder; today's decode ≈ 50–85 KB + 0.5–0.8 ms per instruction in Lean's kernel; a small-body dispatch spike gained 18 % time / 10 % RSS (rest = loop machinery). P′ parsers follow the existing shape (small bodies, reads inside `sub` windows); E4 measures, no target. Measured: the Rust bustools_cli lift (842 KB code) OOM at 28 GiB. Projection (unmeasured): a 16 GiB budget stops near 0.5 MB of code. Modules past the monolithic budget need U2 D5's chunked assembly (proved split equations + per-chunk decode theorems, `decode_eq`'s type unchanged): Tasks amendment — U29c builds it on the real count-only bustools artifact, chunk sizes from its measured chunk RSS + wall per kernel, export assembly included.

# U28b contract — P′ runtime, `Step`, stepper (tier: kernel)

Purpose: the runtime + reduction relation of profile P′ (Decisions: D29 profile P′, EH semantics, Growth policy, System layer) on the representation U28a froze (`docs/contracts/U28a-profile.md` A2 closed types, A3 runtime, A6 obligations), with the reference stepper proven against it. Consumers: U28c (typing + soundness over P′), U28d (machine), U28e (runner + pinned P′ scripts), U28f/U28g (C++ EH), U29 (WASI system claims), every subject (C1 ports them). Normative pins: Wasm 3.0 SpecTec `859d3232` — `1.2` (deftype, `$rollrt`/`$rolldt`/`$unrolldt`, `$subst_*`), `2.1`/`2.2` (type well-formedness, defined-type + global/table import subtyping), `4.0` (configurations: `ref`, `result`, `taginst`, `exninst`, `moduleinst`, `store`, admin `HANDLER_`), `4.1` (values, `$default_`), `4.3` (every rule cited below by name), `4.4` (`$alloctypes`, `$alloctag(s)`, `$alloctable`, instantiation), `7.1` (`Extend_taginst`, `Extend_exninst`, `Extend_store`); testsuite `44f1503f`; reference interpreter `interpreter/script/runner.ml` (null pattern matching). Contract review: consultant-9 (astra: 4 sound / 6 change / 0 reject, every change adopted below).

Shape: one unit, C1 then C2, one landing. C1 changes the representation and the administrative steps it entails; its preservation target = the observable outcomes + stores of the admitted 2.0-profile programs under the representation map, plus every pinned observation below — not step or fuel counts, nor behavior on arbitrary malformed configurations (`ref.null` becomes a redex). C1 and C2 = separately checkable WIP checkpoints; mutation `--update` + full gate run once, on the landing. Production validation + claims keep the 2.0 boundary until U28c (`ModuleValid.profile`); oracle-assisted P′ execution exists only in FVATest's contract harness (E3).

## C2 — P′ rules (each = the SpecTec rule named, in FVA's context style)
- S1 Contexts: `AInstr.handler (n : Nat) (cs : List Catch) (body : List AInstr)` (`HANDLER_ n {catch*}`), placed outside the result label by `try_table`; `BlockCtx` (frame-free) gains a handler layer that does not count toward `k` (`br-handler`, `return-handler`, `return_call_ref-handler`: `br`, `return` and tail calls pass handlers and drop them); `EvalCtx` gains a handler layer for traps alone (`trap-handler`; throws stop at the nearest handler); context rule `handler` (`Step/ctxt-handler`); `handlerExit : [.handler n cs (vals vs)] ↦ vals vs` (`handler-vals`, no arity premise).
- S2 Exceptions: `throw x` (`Step/throw`: tag address `f.inst.tags[x]`, its type expands to `ts → []`, `|vs| = |ts|`; allocate `⟨ta, vs⟩` (operand order) at `a = |s.exns|`; ↦ `[.refExnAddr a, .plain .throwRef]`); `throw_ref` on null ↦ trap (`throw_ref-null`); propagation: `vals vs ++ [exn a, throw_ref] ++ rest ↦ [exn a, throw_ref]` when `vs ≠ [] ∨ rest ≠ []` (`throw_ref-instrs`), out of a label (`-label`) and a frame (`-frame`); at a handler: no clause ↦ `[exn a, throw_ref]` (`-handler-empty`); first clause `catch x l` / `catch_ref x l` matching (`s.exns[a].tag = f.inst.tags[x]`: address identity, imported aliases share an address; the handler's own frame resolves `x`) ↦ `vals fields ++ [br l]` / `vals fields ++ [exn a, br l]`; `catch_all l` ↦ `[br l]`; `catch_all_ref l` ↦ `[exn a, br l]` (both unconditional); a first tagged clause that does not match ↦ the handler with the remaining clauses (`-handler-next` = "otherwise": the tag-address or exception lookup fails or differs); `try_table bt cs body` ↦ `[.handler m cs [.label m [] (vals vs ++ body)]]` (`Step_read/try_table`, `m` = result arity); hosts never throw (Decisions).
- S3 Tail calls: `AInstr.returnInvoke a` (= 3.0 `(REF.FUNC_ADDR a) (RETURN_CALL_REF dt)`, whose closed type a source `Instr` cannot carry; execution reads the callee instance's type, 4.3:176–197, 214–218): `return_call x` ↦ `[.returnInvoke a]` (`Step_read/return_call`); `[ref.func a, return_call_ref y]` ↦ `[.returnInvoke a]`; `return_call_indirect x y` = `CallTarget` ↦ `[.returnInvoke a]`, else trap (3.0 `table.get` + `ref.cast` trap where they occur); frame rule `[.frame n f' (L.fill (vals vs ++ [.returnInvoke a]))] ↦ vals vs ++ [.invoke a]`, `|vs|` = the callee's parameter count, `L` crossing labels + handlers (`return_call_ref-label/-handler/-frame-addr`: the frame, its labels and handlers are dropped before the callee's frame exists; Wasm + host callees). A null `return_call_ref` traps at its occurrence: on well-typed framed invocations a terminal-outcome + store-preserving shortcut for `-label`, `-handler`, then `-frame-null` (frame-local state has no observation after the trap); not equality of reductions on unframed raw configurations.
- S4 Typed references: `call_ref y` (`call_ref-null` ↦ trap, `ref.func a` ↦ `[.invoke a]`; no dynamic type check: validation owns the operand type, execution reads the callee's), `ref.as_non_null` (`-null` ↦ trap, else the value), `br_on_null l` (`-null` ↦ `[br l]`, else the value), `br_on_non_null l` (`-null` ↦ `[]`, else `[v, br l]`).
- S5 Outcomes (`FVA/Spec/Claims.lean`): `Outcome.thrown (s : Store) (a : Nat)` (3.0 result `(REF.EXN_ADDR a) THROW_REF`); `Final c (.thrown s a) := c.store = s ∧ c.instrs = [.refExnAddr a, .plain .throwRef]`; `CallReturns`/`CallTraps` exclude it; `SysFinal`: uncaught exception → abnormal (the address forgotten, per U27's process API).
- Stepper (`FVA/Impl/Exec/Ref.lean`): `Out.thrown a` (the sequence is `[exn a, throw_ref]`) resolved by the enclosing label/frame (one propagation step each) or handler (clause match); `Out.retInvoke a vs` resolved by the frame; `br`/`ret` pass handlers; `HCtx` gains a handler layer; `runDet` normalizes a pending throw to its nearest handler (T4).

## Theorems (kernel-checked, standard axioms)

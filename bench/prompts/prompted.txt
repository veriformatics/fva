This directory contains software and a README that states its requirements. Formally verify the software against them: produce machine-checked proofs that the shipped artifact meets each requirement, or a demonstration that it does not. Lean 4.35 with Mathlib (v4.35.0, already built; this directory is a Lake project that requires it) is installed; wasmtime and wasm-tools are on PATH. There is no network. When you finish, write VERIFICATION.md as CHECK.md describes.

Follow these principles. (1) Keep the part that a human must review — the formal statements and every definition they depend on — as small as possible, and report its size. (2) Link the proofs to the real implementation: prove properties of the shipped artifact, not of a hand-written model, and do not rewrite the source. (3) Do not trust a single checker: replay the proofs through independent proof kernels, and test your checking setup against known false proofs so that it demonstrably rejects them. (4) Provide one check command that a third party can run to confirm all of this.

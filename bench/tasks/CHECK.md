# What to deliver

Write `VERIFICATION.md` in this directory with:

1. For each requirement in `README.md` (R1, R2, …): what you proved, as the exact statement of each theorem (or other machine-checked result) and the file that holds it; or, if the requirement does not hold, the evidence that it fails, with an input that shows the failure; or what you could not prove, and why.
2. How each result is connected to the shipped artifact named in `README.md` (the exact bytes it is about, or the model of the code you wrote instead).
3. The exact commands that a third party runs, from this directory, to check every result, and what output means success.
4. Anything a reviewer must read and trust for your results to mean what you say (definitions, models, scripts), with its size.
